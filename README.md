# Airport Chaos MVP

Install once from the project root:

```bash
npm install
```

Run the server and client in separate terminals:

```bash
npm run dev:server
npm run dev:client
```

Open `http://localhost:5173`.

Production build and local start:

```bash
npm run build
npm start
```

Open `http://localhost:8091`. Render deployment is configured by `render.yaml`.
